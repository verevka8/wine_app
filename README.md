## Запуск

Python 3.13

Из папки `wine_app`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

откройте адресс, написанный в консоле

## Кеширование

Для модели использовал `st.cache_resource`: он хранит один загруженный обьект, 
а `st.cache_data` хранит сериализуемые данные и возвращает копии, поэтому хорошо подходит для таблицы test 
и массива вероятностей, `_model` не кешируется и  изменение `X` приводит к перерасчету

При движении порога вероятности на test берутся из кеша, 
заново вычисляются только метки и метрики, а если вызывать `joblib.load` без декоратора то
модель будет читаться с диска при каждом перезапуске скрипта
